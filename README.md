# Firebird · HackAlem 2026
# Трек - Креативные индустрии

Команда Obsidian. Кейс #79-lite: сервис подбирает до трех event-подрядчиков из каталога и объясняет, почему каждый кандидат попал в выдачу. Исходный код проекта находится в `hack-ca9ed74e-obsidian/firebird`.

## 1. Описание

Заказчик задает город, дату, формат мероприятия, категорию подрядчика, бюджет и при необходимости язык и длительность. Сервис исключает занятых на дату, проверяет формат, бюджет, язык и часы, затем возвращает до трех карточек с конкретным объяснением. Если результата нет, интерфейс различает три состояния: категория отсутствует в городе, кандидаты есть, но условия не прошли, либо подходящих меньше трех.

## 2. Архитектура

React-интерфейс отправляет запрос в Node.js HTTP API. API загружает CSV-каталог в память, валидирует вход через Zod, применяет детерминированные фильтры, ранжирует кандидатов по релевантности описания к формату, цене и ID, затем формирует объяснения. Необязательный внешний AI может выбрать фрагмент источника из разрешенного списка; без ключей работает локальный fallback.

## 3. Стек технологий

TypeScript, React, Vite, Node.js, Zod, csv-parse, Vitest, lucide-react. База данных не требуется, весь каталог читается из `data/catalog.csv`.

## 4. Зависимости

Node.js 22.13+ и pnpm 11.25.0. Основной сценарий не требует платных аккаунтов и внешнего API. После установки зависимостей проект запускается локально.

## 5. Переменные окружения

Шаблон находится в `hack-ca9ed74e-obsidian/firebird/.env.example`. Без `.env` сервис использует `127.0.0.1:3001` и локальные объяснения. `AI_ENDPOINT`, `AI_MODEL` и `AI_API_KEY` нужны только для необязательного внешнего AI; секреты не коммитятся.

## 6. Инструкция по установке

```sh
git clone https://github.com/BAITC-Hacks/hack-ca9ed74e-obsidian.git
cd hack-ca9ed74e-obsidian/hack-ca9ed74e-obsidian/firebird
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
```

## 7. Инструкция по запуску

```sh
pnpm build
pnpm start
```

Откройте http://127.0.0.1:3001. Для разработки можно запустить `pnpm dev`, интерфейс будет доступен на http://127.0.0.1:5173. Проверки: `pnpm check`..

## 8. Сценарий проверки

В интерфейсе есть готовые демо-запросы. Основной сценарий: Алматы, Ведущий, корпоратив, 10.10.2026, 1 000 000 ₸, 6 ч, русский. Должны вернуться три карточки из четырех подходящих кандидатов. Затем выберите пресет с датой 17.10.2026: состав выдачи меняется из-за календаря занятости.

Редкая категория: Алматы, Флорист, свадьба, 10.10.2026, 300 000 ₸. Сервис показывает меньше трех кандидатов и объясняет почему. Запрос без результата: Астана, Декоратор или Алматы, Ведущий, бюджет 100 000 ₸. Пустая выдача объясняется текстом и счетчиками причин отказа.
