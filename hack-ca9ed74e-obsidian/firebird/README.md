# Firebird · HackAlem 2026

Команда Obsidian. Кейс #79-lite: подбор до трёх event-подрядчиков с объяснениями на исходном каталоге из 66 профилей.

## 1. Описание

Заказчик задаёт город, дату, формат мероприятия, категорию, бюджет и при необходимости язык и длительность. Сервис проверяет условия и объясняет выбор или отсутствие подходящих кандидатов. Бронирование и отправка заявок не входят в проект.

## 2. Архитектура

React → HTTP API Node.js → загрузчик CSV → детерминированные фильтры и ранжирование → объяснения по источнику. Необязательный внешний AI выбирает фрагменты из разрешённого списка; при сбое работает локальное объяснение. База данных не требуется.

## 3. Стек

TypeScript, React, Vite, Node.js, Zod, csv-parse, Vitest. Зависимости фиксируются в pnpm-lock.yaml.

## 4. Зависимости

Node.js 22.13+ (проверяется на Node.js 24), pnpm 11.25.0. Для загрузки пакетов нужен интернет; после установки основной сценарий работает без внешних сервисов.

## 5. Переменные окружения

Все значения необязательны; см. `.env.example`. Без `.env` сервис использует порт 3001 и локальные объяснения. AI_ENDPOINT, AI_MODEL и AI_API_KEY задаются только для дополнительного внешнего AI. Секреты не коммитятся.

## 6. Установка

```sh
git clone https://github.com/BAITC-Hacks/hack-ca9ed74e-obsidian.git
cd hack-ca9ed74e-obsidian
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
```

## 7. Запуск

```sh
pnpm build
pnpm start
```

Откройте http://127.0.0.1:3001. Для разработки: `pnpm dev`, интерфейс http://127.0.0.1:5173. Проверки: `pnpm check`.

## 8. Сценарий проверки

Основной пример: Алматы, Ведущий, корпоратив, 10.10.2026, 1 000 000 ₸, 6 ч, русский. В каталоге четыре подходящих кандидата, возвращается до трёх. На 17.10.2026 состав меняется. Флорист в Алматы, свадьба, 10.10.2026, 300 000 ₸: один кандидат. Декоратор в Астане: категории в городе нет. Ведущий в Алматы за 100 000 ₸: кандидаты есть, бюджет не проходит.

Интерфейс и подробные проверки дополняются по этапам разработки.
